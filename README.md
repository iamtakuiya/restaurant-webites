# Laidback Eats — Restaurant Website

A multi-page restaurant website built with React, TypeScript, and Vite.

**Live site:** https://laidback-portfolio-demo.netlify.app/

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | React 18 + TypeScript |
| Build tool | Vite |
| Styling | Sass (SCSS variables / modules) |
| Routing | React Router v6 |
| Icons | Font Awesome |
| Deployment | Netlify |

---

## Features

- Multi-page routing with React Router v6 (6 pages)
- Shared layout with persistent Header / Footer
- Generic, reusable DynamicForm component (TypeScript generics)
- Reservation form with dynamic field config
- Menu section with food / drink categories
- Events gallery and About Us page
- Responsive design across mobile, tablet, and desktop
- Design tokens via SCSS variables (colors, typography, breakpoints)

---

## Pages

| Route | Page |
|---|---|
| `/` | Home |
| `/menus` | Menu |
| `/aboutUs` | About Us |
| `/events` | Events |
| `/reserve` | Reservation |
| `/hoursandlocation` | Hours & Location |

## Getting Started

```bash
git clone https://github.com/takuportfolio/restaurant-website-1.git
cd restaurant-website-1
npm install
npm run dev
```
